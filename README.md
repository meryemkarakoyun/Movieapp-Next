
# 🎬 Movie App (Next.js)

A modern movie discovery application built with **React**, **Next.js**, and **TailwindCSS**. Users can explore popular or trending movies, view detailed information, toggle dynamic light/dark themes, and easily navigate through categories — all powered by the **TMDB API**.

## 🚀 Features

- 🎞️ **Dynamic Theming** – Seamlessly switch between light and dark modes using next-themes.
- 📖 **Movie Details** – Detailed view for selected movies utilizing high-quality backdrops from TMDB.
- ⚡ **Next.js Power** – Fast rendering, optimized performance, and clean client-side navigation.
